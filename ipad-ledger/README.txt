오늘의 가계부 | 아이패드 설치 안내

앱 설치
1. 이 폴더의 파일을 HTTPS 웹 공간에 올립니다.
2. 아이패드 Safari에서 index.html 주소를 열고 공유 버튼 → 홈 화면에 추가를 선택합니다.
3. 홈 화면의 가계부 아이콘으로 사용합니다. 첫 접속 후에는 오프라인에서도 사용할 수 있습니다.

공용 가계부 사용법
- 지출 입력란에서 사용자 A/B 이름을 입력합니다.
- 기록할 때 실제 사용자를 라디오 버튼으로 선택합니다.
- 달력 날짜를 누르면 해당 날짜의 합계와 기록 목록을 확인할 수 있습니다. 날짜별 사용 금액은 달력에도 표시됩니다.
- 날짜를 눌러 선택한 다음 지출을 입력하면 그 날짜에 기록됩니다.

기능
날짜별 지출 입력, 과거 날짜 보완, 금액 빠른 버튼, 카테고리/메모, 하루 및 월 합계, 달력, 어제 미기록 안내, 저녁 기록 시간 설정을 지원합니다.

알림 참고
iPadOS 웹 앱은 서버 푸시를 연결하지 않으면 앱이 닫힌 동안 정해진 시각에 알림을 보내기 어렵습니다. 앱을 열거나 다시 돌아왔을 때 미기록을 알려줍니다. 닫힌 동안에도 울리는 알림이 필요하면 iPad 미리 알림 앱에서 매일 반복 알림(예: 매일 21:00 “가계부에 오늘 지출 적기”)을 설정해 주세요.

개인정보
기록은 이 iPad 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제나 앱 제거 시 기록이 사라질 수 있습니다. 기기 간 동기화/백업은 제공하지 않습니다. 두 사람이 같은 iPad의 같은 앱을 사용하면 함께 기록을 볼 수 있습니다.
